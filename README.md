# CEDRAVA — Media pública

Repositorio público que solo contiene imágenes de posts/carruseles ya publicados o listos para publicar en redes de CEDRAVA. Existe únicamente para darle una URL pública a cada imagen, requisito de la API de Meta para poder publicar contenido vía automatización.

No sube nada aquí que no sea una imagen final de una pieza de marketing — sin contratos, sin datos de clientes, sin información interna.

Las imágenes las sube automáticamente el script `marketing/tools/publicar-redes/publicar.py` del repo `mayte-mx/CEDRAVA_corporativo`, organizadas por carpeta de fecha/hora de publicación.
